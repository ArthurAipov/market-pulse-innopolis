# 3. Сравнение

| | `java.io` | `java.nio` |
|---|---|---|
| Единица работы | поток байт | буфер + канал |
| Блокировка | всегда | опционально (`configureBlocking(false)`) |
| Поток на соединение | 1 : 1 | 1 : N (через `Selector`) |
| Структура данных | нет | [`ByteBuffer`](../ByteBuffer/1.%20Анатомия.md) |
| Готовность к I/O | не спрашивается — блокируется | спрашивается через `Selector`/`SelectionKey` |
| В проекте | `HttpClientTInvestApiClient` (этап 2) | `Reactor` (этап 7) |
| Введено в JDK | 1.0 | 1.4 (NIO), 1.7 (NIO.2 — `Path`/`Files`) |
